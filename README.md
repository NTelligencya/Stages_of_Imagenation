# Stages of Imagenation

A reconstructed portfolio of theatrical stage designs, transformed from remembered fragments into digital reality through AI image generation.

## About This Project

Three A3 sketchbooks containing charcoal stage designs disappeared decades ago. The paper is gone, but the visions persisted—fragments carried intact across thirty years. This project uses AI image generation to reconstruct those lost designs, creating theatrical portfolios for productions that exist only in memory and machine.

## The Designs

- **Blood Wedding** (Federico García Lorca, 1932) — A theatre-in-the-round production set within a dark paper-mâché forest
- **The Glass Menagerie** (Tennessee Williams, 1944) — A ruined church transformed into a memory-space
- **Doña Rosita la soltera** (Federico García Lorca, 1935) — A greenhouse prison of black rose stems
- **The Good Person of Szechwan** (Bertolt Brecht, 1943) — Post-earthquake rubble with isolated pink elements
